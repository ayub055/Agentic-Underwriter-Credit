Design Principles

Architecture Decisions

1. Determinism Over Intelligence

Every risk signal Claude derives from data is a hardcoded Python rule waiting to be written. LLM's job is to narrate pre-computed insights, not derive them. Feature extraction, event detection, key findings — all deterministic and auditable.

2. Fail-Soft Architecture

LLM failures never block report generation. Every LLM call has a fallback. ToolResult.success tracks per-call status. Reports complete with placeholder text even if all LLM calls fail. The pipeline always produces output.

3. Structured Reasoning Trace

Raw data → annotated features → interaction signals → behavioral classification → verdict → LLM narrates. This is what Claude does in its weights. Moving it to Python makes it auditable, reproducible, and improvable without touching the model.

4. Three-Model Split

PARSER_MODEL=mistral (fast JSON, no think tags), EXPLAINER_MODEL=llama3.2 (real-time streaming), SUMMARY_MODEL=deepseek-r1:14b (async, reasoning quality). Swapping a model requires only one line change in config/settings.py.

5. Think Block Transparency

deepseek-r1 reasoning blocks are logged at DEBUG level — never discarded, never shown to users. Allows learning from model reasoning to discover new rules to encode deterministically. Production output is always clean.

6. Typed Inter-Module Contracts

All data between pipeline stages typed via Pydantic v2: ParsedIntent, ToolResult, TransactionInsights, CustomerReport, BureauReport. model_copy(update={...}) for immutable updates. Runtime validation catches violations early.

7. Sub-Package Architecture

Pipeline split into: core/ (5-stage query), insights/ (transaction patterns), reports/ (builders + LLM summaries), extractors/ (bureau CSV parsing), renderers/ (PDF/HTML). Clear responsibility and import boundaries per sub-package.

8. Cache-First Report Strategy

Combined report checks _REPORT_CACHE before rebuilding sub-reports. Key = (customer_id, period). Zero recomputation on repeated requests. Cache cleared on restart — always forces fresh data on new session.

9. Domain Knowledge Roadmap

~20 interaction rules today. Credit risk literature has 200+. Path 1: encode as Python. Path 2: full reasoning trace. Path 3: fine-tune 7B–14B on 500+ labelled reports. Path 5: RAR knowledge base for non-engineer rule authoring.
